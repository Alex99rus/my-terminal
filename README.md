# Мой терминал

Учебный аналог TradingView: живые графики свечей с биржи Binance,
несколько окон с разными интервалами и синхронизацией между ними.

## Как запустить

1. Установите Node.js (LTS) с сайта https://nodejs.org
2. Распакуйте архив, откройте папку `my-terminal`
3. Откройте в этой папке терминал (Windows: в адресной строке проводника напишите `cmd` и нажмите Enter)
4. Один раз выполните: `npm install`
5. Запуск: `npm run dev` — сайт откроется в браузере сам (адрес http://localhost:5173)
6. Остановить: в терминале нажмите `Ctrl + C`

## Что где лежит

- `index.html` — каркас страницы (верхняя панель, место под график)
- `src/main.js` — главный файл: раскладка окон, верхняя панель, синхронизация
- `src/layout.js` — раскладки окон и границы между ними (их можно тянуть мышью)
- `src/snapshot.js` — снимки графиков в высоком разрешении
- `src/drawings.js` — рисование: линии, лучи, прямоугольник, Фибоначчи
- `src/indicators.js` — формулы индикаторов (EMA, SMA, RSI, MACD…)
- `src/paper.js` — демо-счёт: виртуальные ордера, позиции, стопы, история
- `src/paperUI.js` — панель демо-счёта внизу экрана
- `src/chartSettings.js` — окно «Настройки графика»: цвета, фон, линии, перекрестие
- `src/localTime.js` — время на шкале по часовому поясу пользователя
- `src/dayLines.js` — вертикальные линии: границы дня (до 1ч), недели (4ч), месяца (1Д) и года (1Н)
- `src/traderAssistant.js` — индикатор Trader Assistant (таблица по дневному ATR)
- `src/indicatorsDialog.js` — окно «Индикаторы»
- `src/watchlist.js` — список монет справа с живыми ценами
- `src/alerts.js` — оповещения о цене: проверка, звук, уведомления, список
- `src/smartAlerts.js` — умные оповещения: индикаторы, закрытие свечи, движение цены
- `src/toolbar.js` — панель инструментов рисования слева
- `src/pane.js` — одно окно графика (свечи, объём, легенда, выбор интервала)
- `src/binance.js` — запросы к бирже Binance (история и живые цены)
- `src/bybit.js` — то же для биржи Bybit
- `src/markets.js` — список рынков: Binance и Bybit, спот и фьючерсы
- `src/style.css` — оформление (цвета, отступы)
- `package.json` — список библиотек и команд проекта
