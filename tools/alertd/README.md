# alertd — сигналы на телефон

Маленький сервер на вашей машине: терминал отдаёт ему оповещения о цене, он сам следит за ценой
и присылает сообщение в Телеграм, даже когда терминал закрыт. Только стандартная библиотека Python.

## Установка (на сервере, под root)

    curl -fsSL https://raw.githubusercontent.com/Alex99rus/my-terminal/main/tools/alertd/install.sh -o /tmp/alertd-install.sh && bash /tmp/alertd-install.sh

Скрипт спросит токен нового бота из @BotFather (создайте **отдельного** бота, не торгового), найдёт ваш чат,
поставит службу `alertd` и подключит её к nginx (`/api/`). В конце покажет секретный ключ.

## В терминале
🔔 → «📱 Сигналы на телефон» → вставить ключ → «Проверить» (на телефон придёт тестовое сообщение).

## Что умеет
Только оповещения о цене (линия 🔔). Умные оповещения и оповещения на рисунках — пока только в открытом терминале.
Состояние хранится в `/var/lib/alertd/alerts.json`. Логи: `journalctl -u alertd`.
