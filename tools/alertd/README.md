# alertd — сигналы на телефон

Маленький сервер на вашей машине: терминал отдаёт ему оповещения о цене, он сам следит за ценой
и присылает push-уведомление на телефон (как у TradingView), даже когда терминал закрыт.
Нужен только пакет `python3-cryptography` (ставит установщик). Телеграм по желанию (`ALERTD_BOT_TOKEN`, `ALERTD_CHAT_ID` в `/etc/alertd.env`).

## Установка (на сервере, под root)

    curl -fsSL https://raw.githubusercontent.com/Alex99rus/my-terminal/main/tools/alertd/install.sh -o /tmp/alertd-install.sh && bash /tmp/alertd-install.sh

Скрипт ставит службу `alertd`, подключает её к nginx (`/api/`) и в конце показывает **ссылку с секретным ключом**.

## На телефоне
1. Добавьте сайт на экран «Домой» (на iPhone это обязательно).
2. Откройте показанную ссылку (ключ запомнится и пропадёт из адреса).
3. 🔔 → «Включить на этом устройстве» → разрешить уведомления → «Проверить».
На Android отключите экономию батареи для сайта, иначе уведомления могут опаздывать.

## Друзья
У каждого человека свой ключ, свои оповещения и свои телефоны.

    alertd-user add Вася     # покажет ссылку для Васи — отдать только ему
    alertd-user list         # кто подключён
    alertd-user del Вася     # отключить (ключ перестаёт работать сразу)

Друг открывает свою ссылку на телефоне (сайт на экране «Домой») → 🔔 → «Включить на этом устройстве».
Уведомления идут с вашего сервера, до 50 человек.

## Сообщения всем
    alertd-user say "текст"     # и пуш на все подключённые устройства, и плашка в терминале у всех
    alertd-user push "текст"    # только пуш (тем, кто включил сигналы)
    alertd-user news "текст"    # только плашка сверху в терминале (видит любой, кто открыл сайт, один раз)
    alertd-user news-off        # убрать плашку
Плашка появляется при открытии терминала или в течение 10 минут. Рассылать может только владелец (ваш ключ).

## Что умеет
Оповещения о цене (🔔) и оповещения на линиях и лучах («пересечение») приходят на телефон; у каждого устройства свой список — они не стирают друг друга.
Умные оповещения и «закрытие свечи» сервер не отслеживает сам, но если терминал открыт на любом вашем устройстве, их сигнал тоже придёт на остальные устройства.
Состояние — `/var/lib/alertd/alerts.json`, ключи сервера — `/var/lib/alertd/vapid.json`. Логи: `journalctl -u alertd`.
