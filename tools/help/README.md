# Запись видеоинструкции

Ролики из окна «❓ Помощь» делаются автоматически: скрипт открывает терминал на подставных данных
(без интернета), «нажимает» кнопки по сценарию, озвучивает русским голосом и собирает mp4 с субтитрами.

## Как перезаписать

```
npm run build
pip install playwright numpy sherpa-onnx==1.12.40    # один раз; нужны ещё ffmpeg и Chrome
python3 tools/help/record.py all --check             # все главы; --check проверяет, что озвучка понятна
python3 tools/help/record.py draw                    # одна глава
```

Результат — `public/help/<глава>.mp4` и `.jpg`. Длины, которые напечатает скрипт, впишите в `len` в `src/help.js`.
Голос (по умолчанию `irina`) скачивается сам; другие: `--voice ruslan|denis|dmitri`, скорость — `--speed 0.92`.

## Как менять сценарий

Главы — в `chapters.py`. `s.say('подпись', 'текст для голоса')` запускает озвучку, действия мыши идут, пока голос говорит.
Текст для голоса пишем так, как читать: Энтер, Шифт, Трейдинг Вью, эр-эс-ай. Если `--check` выводит «плохо слышно» — перепишите слово.
Изменили функцию в терминале — поправьте сценарий и текст шагов в `src/help.js`, перезапишите главу.
